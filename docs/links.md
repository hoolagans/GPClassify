## Contributing & Links

**Who this is for:** Users contributing docs, examples, or release updates.

**When to use it:** During maintenance, release prep, and issue triage.

- Package: https://pypi.org/project/gpclassify/

### Docs governance and release checklist

README is the source of truth for core examples and parameter descriptions. Keep docs pages synchronized with README for every release.

Release checklist:
- [ ] Reconfirm examples in README and docs are copy-paste runnable.
- [ ] Reconfirm defaults and parameter docs match current code.
- [ ] Verify all docs links resolve.
- [ ] Review API and examples pages before tagging release.

Ownership:
- Primary owner: repository maintainers.
- Review cadence: at least once per release and during significant API changes.
