## GPClassify

**Who this is for:** Python developers and researchers who want an interpretable, scikit-learn-style genetic programming classifier.

**When to use it:** When you want tree-based symbolic models that you can inspect as readable expressions or tree text.

### Why GPClassify

- Scikit-learn-style fit/predict API.
- Supports binary and multiclass classification.
- Human-readable model inspection via expression and tree views.
- Fitness controls for accuracy, F1, and Pearson R².

### Install

```bash
pip install gpclassify
```
